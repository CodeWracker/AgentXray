MISLEADING-ARTIFACT RISK:
- CLAHE / histogram equalization (A01-P1, A02-P1, A03-P2, A03-P5, A04-P1, A05-P1, A06-P1): amplifies grain into speckle that mimics subchondral cysts or focal sclerosis; tile-boundary halos; banding. GUARD: dual-strength variants must concur (A02-P1, A04-P1); every candidate must be traceable as a faint real density difference in the ORIGINAL at identical crop/zoom.
- Edge/high-pass filters (A01-P5, A02-P2, A03-P3, A04-P3, A05-P3, A06-P1): respond to ANY sharp transition — trabecular striations, grain, normal cortices, film scratches — producing false "fracture lines"; halos on both sides of strong edges can mimic double cortices. GUARD: (a) candidate line must be visible in the unprocessed original along its full length; (b) anatomical plausibility (cuts across, not along, trabecular flow; does not run with a cortical edge or cross a joint space; endpoints meet cortex); (c) corroboration by a second independent edge method (A04-P3) and/or persistence across two window settings (A04-P2). A line existing only in the enhanced image is an artifact, full stop.
- Deconvolution (A04-P7): HIGHEST RISK in the council — regularized deconvolution is notorious for phantom streaks that look exactly like fracture lines, and it is the one method whose artifact class is indistinguishable from its target finding. GUARD: exploratory status only, zero diagnostic weight; a "line" must persist across several regularization strengths and agree with original edge locations; if it fails either check it is rejected.
- Bone subtraction (A02-P3, subtraction component): residual halos around bone margins mimic calcification; over-subtraction erodes the true soft-tissue–bone boundary and distorts the silhouette. GUARD: any new density hugging a bone edge and present only post-subtraction is rejected; the silhouette must match the original foot contour.
- Flat-field / de-vignetting (A02-P5, A03-P1, A05-P4, A06-P5): division by an estimated background can (a) erase genuine broad low-frequency signal (a real diffuse lucency, a broad swelling), (b) create curved brightness artifacts that mimic periosteal reaction, (c) amplify noise in the darkest regions. The collimation/field edge itself is a straight high-contrast line — a classic fracture mimic (A06-P5 names it). GUARD: post-correction image must show the SAME anatomy on a flatter background; if correction changes any bone's apparent density or shape, distrust the corrected image in that region and prefer the original; classify each faint line as bone-conforming (real) vs crossing empty space (scratch, A05-P4).
- Denoising (A05-P2, A03-P3's median pre-step): over-denoising smears real fine trabeculae and faint fracture lines into a waxy texture — it can MASK exactly the findings we seek. GUARD: run at two conservative strengths; a candidate lesion that vanishes on denoising implicates noise; verify no thin cortex was smoothed away. Denoising should be a comparison variant, never the sole pre-processing.
- Magnification/resampling (A03-P5, A06-P2): Lanczos ringing/ripples along sharp cortices can be misread as osteophytes or step-offs; soft interpolation erases the 1 mm detail being sought. GUARD: sharp resampler only; magnification adds no real resolution — it is a second look, and the original at native scale is the arbiter; report joint widths as qualitative/relative pixels, not mm (no physical scale reference exists in the file — A06-P2's "locally calibrated mm" is pseudo-precision; see MY VOTES).
- Angle measurement (all angle proposals): landmark misidentification under superimposition (fibula over tibia, talar head), and systematic bias if the beam is off true lateral. GUARD: overlays of every traced line on the original are mandatory; report values with an explicit uncertainty band; run the rotation check FIRST (A06-P4) and interpret angle deviations relative to the quantified rotation; do not call an angle abnormal unless it is outside the normal range by more than the estimated measurement error (A06-P4's rule, adopted).
- Segmentation (A06-P3): the bright beam-field rectangle and background non-uniformity can break threshold-based skin-line extraction. GUARD: manual correction of segmentation slips; contour must lie exactly on the visible skin edge at every point; standardized reference points for heel-pad measurement.
- Global caveat for ALL enhanced images: the upper-left leg fade and the vertical gradient mean the background is not uniform; any "structure" that follows the gradient or the streak lines rather than the anatomy is an artifact.
