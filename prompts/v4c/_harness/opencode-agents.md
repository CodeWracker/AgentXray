Sub-agents are created with the `task` tool, always with `subagent_type` set to `analyst`, which runs the same model as you. Each call starts a fresh, independent session that does not see this conversation, so every task description must be self-contained: give the agent its persistent name (for example `Agent_03`), the absolute path of the run directory, which files it must read or view, what it must write and where, and the phase it is in. Every sub-agent receives `AGENTS.md` automatically; tell it which name to use in `log_action` and to follow the AGENT LOG, ENVIRONMENT and REPRODUCIBILITY AND ISOLATION sections before proposing or running analyses. During independent phases, do not include other agents' opinions in the task description.
